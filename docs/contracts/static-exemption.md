# 精确静态内容免检契约（C-04）

版本：1.0.0（2026-10-03，固定契约）

## 1. 契约目标与安全边界

本契约用于在保证敏感信息检测安全的前提下，对经过事前安全审批、内容公开、完全确定的静态提示词（如系统通用 System Prompt、固定的客服法律免责声明等）实施**精确边界免检（Exact Exemption）**。

### 安全铁律

1. **精确内容与精确边界双重相等**：
   只有当输入文本与受信任清单中注册的静态模版在字符级 **100% 完全精确一致**（包含全部空格、换行、标点及大小写）时，才被判定为 `EXEMPT`。
2. **改单字、调空格、大小写不一致立即失效**：
   任何细微修改（例如错别字替换、添加末尾空格、修改标点）均使免检失效，判定为 `NOT_EXEMPT`，必须强制进入敏感检测流水线。
3. **动态变量与占位符永远不继承免检**：
   在模版中插入任何变量（如 `{user_name}`、`{{order_id}}`）或动态生成的内容，绝不享有免检资格。
4. **不可分离组合强制全量检测**：
   静态前缀/提示与用户动态输入拼接在同一字段且无严格协议边界分割时，整体强制判定为 `NOT_EXEMPT`。
5. **客户端自称免检无效**：
   客户端在请求体中声称 `exemption_claimed: true` 或指定未注册/不属于当前保护域的 `template_id`，一律无效或被拒绝，不得绕过检测。
6. **不使用真实秘密测试免检放行**：
   测试体系使用公开无害的合同样本，验证免检时检测器 Spy 调用为 0，未免检时检测器 Spy 调用为 1。

## 2. 字段规范与注册清单

受信任免检清单（`StaticExemptionRegistry`）包含：
- `version`: 清单版本号；
- `templates`: 模版数组，每个包含：
  - `template_id`: 模版唯一标识（如 `sys-prompt-finance-v1`）；
  - `domain`: 归属的保护域（如 `finance-ops`）；
  - `version`: 模版本身版本；
  - `text`: 模版完整纯文本；
  - `sha256`: `text` 的 UTF-8 编码 SHA-256 小写十六进制摘要。

## 3. 场景覆盖与正反例

1. **正例（精确匹配免检）**：输入与模版内容完全一致 -> 判定 `EXEMPT`，检测器 Spy 调用计数为 0。
2. **反例（改单字/改标点）**：将 "请以专业态度回答" 改为 "请以专业态度作答" -> 判定 `NOT_EXEMPT`，检测器 Spy 被调用。
3. **反例（修改空白字符）**：模版末尾多一个换行符或空格 -> 判定 `NOT_EXEMPT`，检测器 Spy 被调用。
4. **反例（混入动态变量）**：静态提示后拼接了 `{company_name}` 或用户的提问 -> 判定 `NOT_EXEMPT`，检测器 Spy 被调用。
5. **反例（跨域模版引用）**：`hr-ops` 域的请求引用了 `finance-ops` 域的模版 -> 判定 `NOT_EXEMPT`，检测器 Spy 被调用。
6. **反例（虚假/未注册模版 ID）**：客户端声称模版 ID 为 `fake-template-id` -> 判定 `NOT_EXEMPT`，检测器 Spy 被调用。
