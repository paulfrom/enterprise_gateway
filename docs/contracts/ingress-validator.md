# 网关入口综合验证契约（P-04）

版本：1.0.0（2026-10-03，固定契约）

## 1. 契约目标与安全边界

本契约作为网关接收大模型调用请求的第一道安全屏障（Barrier），综合整合以下三道核心门禁：
1. **外发分级政策门禁（C-01）**：确保请求分类经过受信政策解析，且属于 `APPROVED_EXTERNAL`；高敏、不可外发或未知分类一票否决。
2. **两协议候选文本契约门禁（C-03）**：对 DeepSeek Chat Completions 与 Claude Messages 请求进行逐字段严格校验，拒绝图片、文件、流式、思考块、工具调用及未知/重复字段；绝不剥离字段后静默透传。
3. **精确静态内容免检门禁（C-04）**：提取待处理业务文本切片，精确核对静态内容免检清单，对 100% 精确一致的模版标记为无需检测，其余文本全部标记为必须执行敏感检测。

## 2. 行为准则

- **整请求拒绝**：若任何一个字段或政策规则不符，整请求强制拒绝，模拟上游调用计数为 0。
- **零回显**：错误响应一律不包含提交的业务正文、Token 或凭据。
