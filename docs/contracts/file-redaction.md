# 文件脱敏契约

## 入口和结果

管理员在 `/admin/documents` 选择文件、预览脱敏文字并下载 `redacted.md`。后端入口：`POST /api/admin/documents/redact?format=<格式>`，正文是文件原始字节，Content-Type 为 `application/octet-stream`。使用已有管理员 Cookie、同源 Origin 和 `X-Admin-CSRF`。只接受固定格式枚举，不接受文件名、路径、租户、保护域、政策或模型参数，不支持 multipart。

鉴权、同源和 CSRF 校验先于正文读取。管理员 scope 必须等于部署的 `tenant_id/domain`，结果交付前重新验证会话。文件服务不调用供应商，不需要 BYOK 或外发分类，不写模型历史、知识采集、原文件或持久映射。解析和检测只使用内存及受限子进程。

成功响应包含 `format`、`output_format=markdown`、`redacted_text`、`characters`、`block_count`、`entity_count`、`replacement_count`、`entity_types`、静态 `warnings` 和检测版本 `package_hash`。不返回原文、文件名、路径、解析器诊断或原值映射。同文件内同类型同原值使用一致的类型/角色占位符，各文件独立编号，相同编号不表示跨文件同一实体；不提供回填。下载是新生成的文字产物，不保留原版式，也不代表原文档容器已脱敏。浏览器离开页面、清除、退出或会话失效后清除本页状态；已下载文件由用户管理。

## 格式边界

| 格式 | 行为 |
| --- | --- |
| TXT、MD、JSON、YAML、YML | 严格 UTF-8 / UTF-8 BOM，处理全部文字，包含键名、链接和 HTML 字面量；无效编码或 NUL 拒绝 |
| CSV | 读取字段及多行单元格，生成 Markdown 表格 |
| DOCX | 合并跨 run 文本，读取简单表格、页眉页脚、批注、脚注尾注及修订文字；图片、嵌入对象、SmartArt、嵌套表格和不支持内容阻断 |
| XLSX、XLSM | 包含表名、隐藏工作表/行/列、公式文字、批注及作者；宏不执行、不交付并提示省略；图片、图表、外部链接及嵌入对象阻断 |
| XLS | 只读取表名及缓存单元格值，固定提示 `XLS_CACHED_VALUES_ONLY`，无法审查公式和其他对象；建议先转为 XLSX |
| PDF | pypdf 读取文字页，不保留版式；加密、无文字页、图片/Form XObject、附件及注释阻断；不提供 OCR |

旧版 DOC 须自行转换为 DOCX。JSON/YAML 作为文字处理，输出不保证原格式有效性。元数据、链接目标、宏和原容器不进入产物。参考 `tuomin-open-source` 的结构化提取→脱敏→Markdown 组织方式，采用独立内存解析实现，PDF 使用 pypdf。PDF 提取边界见 [pypdf 官方说明](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)。

## 检测、安全和限额

复用运行期规则、词典和本地 NER，处理前验证完整版本包。所有提取文字执行必需检测，不采用聊天快速筛选，不继承聊天 `passthrough` 配置。先检测原始字段，再替换和转义 Markdown 表格。高敏秘密、保留占位符、解析/检测故障、版本不一致均拒绝整份文件，不返回部分产物。检测取决于规则、词典和模型，需人工核对，不能承诺零漏检。

预览使用普通文字节点，不执行 HTML。文件接口跳过通用入口日志的正文预读取和请求头输出，错误只包含固定码，结果使用管理端 `no-store` 安全头。

上传最多 10 MiB/30 秒，整个请求最多 90 秒；解析子进程最多 20 秒，地址空间最多 2 GiB。每实例同时处理一个文件，繁忙直接拒绝，解析执行器随运行期关闭。ZIP 最多 2048 成员、展开合计 32 MiB、单成员压缩比 200；重复/加密成员和 XML DTD/实体扩展拒绝，不解压到磁盘。文字最多 20 万字符、块最多 1 万、表格最多 10 万单元格/256 列、PDF 最多 200 页，超限不截断。Nginx 单独配置上传上限并关闭请求缓冲。

错误状态：401/403 为会话、同源、CSRF、scope 或秘密阻断；413 为资源超限；422 为格式、损坏、无文字、加密、不支持内容或保留占位符；429 为繁忙；503 为服务/必需检测/版本校验不可用；504 为超时。详细错误码与响应结构以 OpenAPI 为准。
