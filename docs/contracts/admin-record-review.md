# 管理员直接审阅契约

`audit.admin_reader.AdminReviewService` 是内部审计组件，替代已删除的工单/双批准审阅模块（旧 `audit.record_review`、ReviewTicket、ReviewApproval 及申请/批准/消费文件链不保留兼容接口）。管理员经服务端会话取得 `AdminContext` 后直接审阅指定受控证据记录；它直接调用既有 `infra.envelope_crypto.decrypt_record`，不实现另一个加密格式或数据库。

## 输入与信任边界

装配由受信服务提供已有 `KmsProvider`、受控账本目录和服务时钟。每次读取逐次验证管理员会话：身份与管理范围来自 `AdminContext`（actor=admin、部署管理范围、会话关联摘要、认证与到期时间），客户端自报身份头、伪造/过期/已注销会话均拒绝。组件不接收客户端提交的任意密文或文件路径；目标记录及其租户元数据必须由受控审计目录解析现存加密证据后提供。

既有信封 AAD 含域、记录、加密用途和格式版本，不含租户；因此调用方必须保持审计记录与租户元数据的一致可信关联。知识证据与审计证据的存储/密钥权限分离仍由装配保证，禁止把知识域任意密文交给审阅组件。

## 权限规则

| 操作 | 必需身份与范围 | 允许行为 | 拒绝行为 |
|---|---|---|---|
| 查询目录 | 有效 `AdminContext`，本部署租户/域 | 浏览受控审计记录的可信元数据目录 | 无会话、越域、伪造会话 |
| 直接读取 | 有效 `AdminContext`，固定审阅用途 | 对目录中指定的现存有效记录直接 AEAD 解密一次并留痕 | 任意密文/路径、错域、错用途、AAD 篡改、KMS 或审计失败、会话在释放前到期 |

单管理员一次操作即完成合法审阅；没有工单申请、第二角色批准、一次性消费标记或等待审批状态。管理员权限不改变数据生命周期：已到期、已销毁或未产生的正文不能伪造为可读。

## 持久性与故障

访问事件采用已有 `durable_commit`，每次行为事件使用独立文件。事件仅含固定操作/结果码、actor=admin、会话关联摘要、记录句柄摘要、时间和固定作用域，不含证据正文、密码、Cookie、供应商 Key 或密钥材料。

合法读取先可靠记录访问尝试，再执行真实 AEAD 解密，可靠记录访问结果后才返回明文。解密完成及最终审计落盘后均重新校验会话有效期：KMS 或审计耗时跨过会话截止时没有明文返回。KMS/认证失败拒绝读取；访问审计失败绝不释放明文，返回 `AUDIT_WRITE_FAILED`；存储本身不可用时不伪称拒绝日志已成功落盘。

服务崩溃遗留状态按既有持久写入契约恢复，判断访问结果未知，不伪造成功。底层 Windows 目录 fsync 的限制继承既有写入契约，生产卷持久性另行验证。

读取接口一次仅返回指定记录 `bytes`，没有列举正文、批量读取或原文导出方法。返回的获准原文属于企业审计可信区，不能再写普通日志或交外部模型。

## 可证明的范围

测试使用真实 AES-GCM、真实持久文件、真实管理员会话以及现有 `EvidenceGate` 生成的加密留证；KEK、身份和正文均明确为合成材料。覆盖并发竞争、重启重放、会话到期竞态、AAD 篡改、KMS/写盘故障。组件验证不代表真实企业 KMS 或生产卷验收，不启动真实业务资料批量导出。
