# 独立质量口径与划分审计契约（C-06）

版本：1.0.0（2026-10-03，固定契约）

## 1. 契约目标与安全边界

本契约用于在脱敏网关进入敏感信息检测实现（D组任务）及真实评估前，固化**数据集独立划分审计规则**与**敏感信息检测质量评价口径契约**。

### 安全铁律

1. **严格数据集无交集划分**：
   训练集（Train）、开发验证集（Dev）与评测独立测试集（Test）必须在样本 ID 和文本内容 SHA-256 摘要两个维度实现 100% 互斥（Disjointness）。任何形式的样本交叠（数据泄露或污染）一律判定为审计失败（`DATASET_CONTAMINATION`）。
2. **禁止盲测数据反向泄露**：
   禁止使用测试集调参、选择规则或挑选 NER 模型；测试集仅作为封存验收的单向检验。
3. **秘密泄漏一票否决（Hard Failure）**：
   测试样本中任何已标注的受保护秘密（`SECRET`）若被网关漏检放行，判定为整体验收一票否决（`HARD_FAILURE_SECRET_LEAKED`），绝不允许以高总体召回率平均抵扣。
4. **零泄漏的置信区间上界约束（$3/n$ 规则）**：
   即使在评测中观察到 0 次秘密泄漏，95% 置信水平的单侧上界仍约为 $3/n$（例如 500 个样本无泄漏，其真实泄漏率上界仍约为 0.6%），契约中必须明确记录该上界，不向业务方作出不可证伪的“绝对零泄漏”数学承诺。
5. **未批准门槛不得宣称通过**：
   未经过业务/安全主管正式批准的评测报告，状态必须固定输出为 `UNAPPROVED_THRESHOLDS`。
