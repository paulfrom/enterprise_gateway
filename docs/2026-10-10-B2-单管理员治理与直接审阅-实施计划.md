4b. 重写 `enforce_publication_admission`（BEFORE INSERT ON knowledge_publications；设计 §1.3）：

```sql
CREATE FUNCTION enforce_publication_admission() RETURNS trigger LANGUAGE plpgsql AS $$
DECLARE v_src RECORD;
BEGIN
    IF current_user <> '<ADMIN_ROLE>' THEN
        RAISE EXCEPTION 'KNOWLEDGE_PUBLISHER_REQUIRED';
    END IF;
    IF nullif(current_setting('app.admin_context',true),'') IS DISTINCT FROM 'true' THEN
        RAISE EXCEPTION 'KNOWLEDGE_ADMIN_CONTEXT_REQUIRED';
    END IF;
    IF NOT EXISTS (SELECT 1 FROM knowledge_admin_actions a
        WHERE a.admin_action_id = NEW.admin_action_id
          AND a.action_type='publish' AND a.result='succeeded'
          AND a.object_type='candidate' AND a.object_id = NEW.candidate_id::text
          AND (a.object_version IS NULL OR a.object_version = NEW.candidate_version::text)
          AND a.tenant_id = NEW.tenant_id AND a.domain = NEW.domain) THEN
        RAISE EXCEPTION 'KNOWLEDGE_ADMIN_ACTION_REQUIRED';
    END IF;
    PERFORM 1 FROM knowledge_candidates
     WHERE candidate_id=NEW.candidate_id AND candidate_version=NEW.candidate_version FOR UPDATE;
    IF NOT FOUND THEN RAISE EXCEPTION 'KNOWLEDGE_CANDIDATE_VERSION_NOT_FOUND'; END IF;
    -- 贡献来源完整性：候选全部贡献来源（沿用 storage.py 现有候选→来源关联查询）必须全部绑定
    IF EXISTS (<候选贡献来源> csl WHERE NOT EXISTS (
        SELECT 1 FROM knowledge_publication_sources ps
         WHERE ps.publication_id=NEW.publication_id
           AND ps.source_id=csl.source_id AND ps.source_version=csl.source_version)) THEN
        RAISE EXCEPTION 'KNOWLEDGE_PUBLICATION_SOURCE_MISSING';
    END IF;
    -- 固定锁顺序：来源按 (source_id,source_version) 升序，再锁治理版本
    FOR v_src IN SELECT source_id, source_version, governance_version_id
        FROM knowledge_publication_sources
       WHERE publication_id=NEW.publication_id
       ORDER BY source_id, source_version FOR UPDATE LOOP
        PERFORM 1 FROM knowledge_sources s
         WHERE s.tenant_id=NEW.tenant_id AND s.domain=NEW.domain
           AND s.source_id=v_src.source_id AND s.source_version=v_src.source_version
           AND NOT s.withdrawn FOR SHARE;
        IF NOT FOUND THEN RAISE EXCEPTION 'KNOWLEDGE_SOURCE_WITHDRAWN'; END IF;
        PERFORM 1 FROM knowledge_governance_versions g
         WHERE g.tenant_id=NEW.tenant_id AND g.domain=NEW.domain
           AND g.source_id=v_src.source_id AND g.source_version=v_src.source_version
           AND g.governance_version_id=v_src.governance_version_id
           AND g.valid_from <= clock_timestamp() AND g.valid_until > clock_timestamp()
           AND NOT EXISTS (SELECT 1 FROM knowledge_governance_versions n
                            WHERE n.supersedes_version_id=g.governance_version_id)
        FOR SHARE;
        IF NOT FOUND THEN RAISE EXCEPTION 'KNOWLEDGE_GOVERNANCE_VERSION_INVALID'; END IF;
    END LOOP;
    RETURN NEW;
END $$;
```

`<ADMIN_ROLE>` 与 `<候选贡献来源>` 在 DDL 构建期以 f-string 注入（前者来自 `init_database(admin_role=...)` 参数；后者复用 storage.py 现有候选来源关联 SQL，不新造关联）。

```python
def assert_no_privilege_path(conn, *, role: str, forbidden_role: str) -> None:
    """Assert `role` has no GRANT/INHERIT path to `forbidden_role` (pg_auth_members closure)."""
    row = conn.execute(
        "WITH RECURSIVE chain(rolname) AS ("
        " SELECT %s::text UNION"
        " SELECT m.rolname FROM pg_auth_members am"
        " JOIN pg_roles r ON r.oid=am.member JOIN pg_roles m ON m.oid=am.roleid"
        " JOIN chain c ON c.rolname=r.rolname)"
        " SELECT count(*) FROM chain WHERE rolname=%s", (role, forbidden_role)).fetchone()
    if row[0]:
        raise KnowledgeSchemaError(f'KNOWLEDGE_ROLE_PATH_FORBIDDEN:{role}->{forbidden_role}')
```

3b. **confirm_source_governance**：校验来源存在/未撤回/未到期 → `expected_governance_version` 与当前有效版本不符 → `KNOWLEDGE_GOVERNANCE_VERSION_CONFLICT` → 新版本行 `supersedes_version_id=当前版本` → **级联保守失效**：同事务把仍绑定旧版本的 publication 全部 tombstone + 失效 outbox + consumer_assets.active=false（设计 §3.1「不自动继承扩大后的受众或期限」）→ 返回新 governance_version_id。期限校验：来源存在保留期限字段时 `valid_until` 不得超出（超出 → 422 `KNOWLEDGE_VALIDITY_EXCEEDS_SOURCE`）。

3c. **publish_candidate**：候选 FOR UPDATE（精确 `expected_version` 不符 → `KNOWLEDGE_CANDIDATE_VERSION_CONFLICT`）→ 证据存在性/纯共现/纯模型自证准入（沿用现有判定函数）→ **多来源检查**：贡献来源集合 S（复用 T1 关联查询）；对每来源取「当前有效治理版本」（无 → `GOVERNANCE_MISSING`；被替代 → `GOVERNANCE_SUPERSEDED`；来源 withdrawn/expired → `SOURCE_WITHDRAWN/SOURCE_EXPIRED`）→ `set(audiences) ⊆ ∩ gv.consumer_audiences`（否 → `AUDIENCE_DENIED`；交集空 → 拒）→ `use` 必须等于每个 gv 的 `intended_use`（否 → `PURPOSE_DENIED`）→ `valid_until ≤ min(gv.valid_until, 来源保留期限)` → INSERT admin action → `publish_transactional(...)`（publication_sources 每来源一行绑 gv；幂等键冲突 → 返回已有 publication_id，无新 outbox）→ outbox PUBLISHED 事件含 publication/gv/资产谱系统一标识。

3d. **revise_candidate**：旧行不动；INSERT 新 candidates 行（`derived_from=旧 candidate_id`、`candidate_version=旧+1`、应用 modifications）；旧证据行原位保留。

3e. **withdraw_source**：`invalidate_knowledge_source` 语义保留（tombstone+outbox+consumer_assets 失效），**原始 ACL 不再清空**（设计 §1.2：保留作证据，靠 withdrawn+授权判定阻止消费）；入口绑 admin action。

3f. **revoke_publication**：沿用 `revoke_transactional`（候选→withdrawn、assets 失效、tombstone、outbox REVOKED），角色检查换 admin action。

3g. **evaluate_availability**：按 §3.2 表实现——治理状态（未确认/可发布/拒绝/已替代）、消费资格（有效授权交集+生命周期；未指定 consumer/use → `not_evaluated`）、投递（outbox 与 receipt 实数；无资产 → 空 tuple；撤回无回执 → `invalidation_pending`）、证据状态（available/expired/destroyed/corrupted/key_unavailable/unknown）；`evaluated_at=now`、`state_version` 取服务端快照计数；缺依赖 → `unknown`，不显示可用。
