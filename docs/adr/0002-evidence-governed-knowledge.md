# 知识候选独立于在线检测

用户确认知识库需要真实企业实体、来源证据和原始权限。真实知识是敏感资产，不能称为匿名导出；共现与模型输出不自证业务事实。候选经管理员验证后直接发布（单管理员一次提交，见 ADR 0007），消费权限取全部贡献来源当前有效治理授权的交集，来源失效须传播撤销。

长期权威存储选择PostgreSQL普通关系表及事务outbox；独立worker消费用途隔离的加密spool。在线检测仅消费批准快照。当前无多跳查询规模证据，不加入AGE、Redis或消息中间件；内存领域实现只用于框架验证，不充当生产存储替代品。

2026-10-10 补充决策：DDL v2 以管理员动作、来源治理版本和发布来源绑定承载直接治理，删除人数和审批角色槽准入。原始处理 ACL、来源证据和 unverified 身份保留；显式治理可以授予处理 ACL 之外的合法消费受众，但发布须满足全部来源的用途、受众交集与期限。动作、候选状态、发布、全部来源绑定和 Outbox 在同一事务提交，失败回滚后独立记录失败动作。消费者资产与回执同事务提交，回执不替代有效授权。
