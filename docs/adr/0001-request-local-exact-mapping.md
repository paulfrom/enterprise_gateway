# 原值映射与知识实体归一分离

请求内映射只存当前请求对象内存，不使用Redis或审计回补。没有跨进程恢复长连接的需求证据，共享映射只会扩大原文等价物的暴露面及故障依赖。

四阶段历史对照作为独立加密敏感资产保存，组合正文可能推断出原值对应关系；其访问范围与留存边界见0006。此查询需求不引入跨请求恢复映射或审计回补。

占位符生成方式由 ADR 0011 替代原 HMAC 摘要：按请求内的类型/角色前缀递增编号，不规范化原值。保护域仍由入口、映射对象和流水线共同校验，编号本身不承担跨域认证。知识归一允许把别名关联到企业实体，但不能改变精确回填。保留命名空间字面量直接拒绝，不引入转义兼容协议。
