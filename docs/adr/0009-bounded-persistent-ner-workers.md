# 有界常驻 NER 工作进程与业务评测契约

## 决策

本决策的逐任务文件校验、预热、回收与调度部分由 ADR-0010 的不可变快照与合批契约更新；其余失败关闭、偏移恢复和请求数据边界继续适用。

在线默认 NER 使用专用 `NerWorkerPool`。每个执行槽独占一个通过 spawn 创建的工作进程，一次只执行一个请求任务；tokenizer、ONNX Session 和窗口合并器在该进程内跨任务复用。工作进程按需首次初始化，初始化消耗该任务的时间预算。默认一个执行槽、四个等待任务；等待队列为零时允许占用空闲槽，所有需排队的任务立即拒绝。

通用 `InferenceExecutor` 保留一次任务一个进程、交付结果前确认进程退出的既有契约，用于显式注入的检测器和单次进程性能对照。常驻池成功返回只表示当前任务完成，不表示工作进程退出。

## 进程生命周期与失败

提交时建立唯一任务编号与固定 monotonic deadline。排队、工作进程启动、模型初始化、完整性检查、分词、推理、解码和任务交付均受此预算约束；不得在取得执行槽后重新计时。

排队取消或排队预算耗尽立即移除任务，不启动推理，也不终止正在服务其他请求的进程。运行中取消、超时、进程崩溃、无效结果帧或检测异常终止该槽的工作进程，并通过 join 确认退出；必要时使用 kill。确认退出前不能释放槽或启动替代进程。预算耗尽的结果即使已到达也不交付；结果帧任务编号必须与当前任务一致。

每个工作进程默认最多成功完成 256 个任务，达到上限后回收；该回收包含在任务预算内。工作进程在下一次实际任务到来时重建。关闭池拒绝全部排队任务、终止活动和空闲进程并等待槽线程退出，关闭后禁止提交。

解释器退出时，在 multiprocessing 等待子进程之前统一关闭仍存活的池，终止并 join 空闲工作进程，释放快照描述符；命令行失败退出也执行同一资源回收。池注册使用弱引用，已明确关闭的池从注册表移除。

异常跨进程仅携带注册安全错误码或异常类型，父进程重建异常，不携带业务正文、异常原消息或 traceback。规则、词典与 NER 完成后才能交付完整检测结果，失败不交付部分结果；既有检测故障模式与请求总预算仍适用。

## 模型版本与请求数据

池绑定首次提交的 manifest 字节 SHA-256；manifest 声明整个模型包及来源信息。每个工作进程加载时执行完整制品门禁；每个任务仍重新校验包内文件集合、SHA-256 与长度并核对 manifest，不使用路径、文件大小或 mtime 代替内容校验。模型、tokenizer、配置或许可证变更拒绝请求。发布新模型须创建新池与新流水线装配，在途请求保持原版本。

本次改造保留请求入口的完整组件版本校验；不可变制品快照与指纹缓存属于后续单独决策。执行槽数、等待上限、回收上限、ORT 线程数及执行模式参与保护包版本绑定。

仅复用模型运行资源；请求文本、窗口、logits 与跨度结果为任务局部对象，在任务结束后释放引用。恢复映射保持单次请求生命周期，不进入工作进程、不缓存到模型资源、不用于跨请求恢复。常驻进程不承诺原生分配器立即清零已释放的内存，进程退出仍是完整释放进程内存的边界。

## 业务样本和性能基线

标准测试夹具使用显式标记的合成业务样本，覆盖客服、合同、财务、人事、规则格式、低风险文本、秘密阻断、Unicode、多片段及长文本跨窗口和尾部实体。金标使用 Unicode code point 半开区间，必须校验实体类型、范围、重复跨度及样本标识唯一性。

业务评测走生产滑动窗口与偏移恢复，不截断文本。分别统计 NER 实体精确匹配、完整规则/词典/NER 检测、敏感实体与字符覆盖、负例误报、秘密阻断、筛选误跳过及检测失败。精确匹配要求实体类型、起点与终点同时一致；掩码覆盖按预测跨度并集计算，避免类别差异掩盖实际覆盖效果。

性能对照使用相同模型、样本、窗口、线程数和负载配置，区分独立冷启动探针和后续工作负载。记录各阶段 P50/P95/P99、吞吐量、进程数量和工作进程峰值 RSS，并核对跨模式预测等价性及重复运行确定性。初始化耗时与工作进程启动耗时存在包含关系，不能直接相加。单次进程模式的排队与解释器启动合并观测，常驻模式独立记录排队时间。

真实业务样本从仓库外读取，运行报告必须写到仓库外。报告只包含聚合指标、固定场景分类、配置、运行环境与样本/制品哈希，不写入正文、实体表面值、原始预测或异常消息。默认功能等价检查不代表业务质量已合格；业务覆盖验收阈值必须由部署方显式指定，并继续用真实业务样本校准。
