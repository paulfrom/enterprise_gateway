# 不可变 NER 制品快照与有界合批

## 决策

Linux 在线 NER 将已验证模型包复制到匿名 memfd；复制时逐文件检查完整文件集合、SHA-256 和字节数，验证配置与许可声明，随后施加 F_SEAL_WRITE、F_SEAL_GROW、F_SEAL_SHRINK、F_SEAL_SEAL。不得以 chmod、mtime 或文件大小缓存替代不可变性。某些 Python 构建缺少 memfd 包装时使用 libc 的同一接口；无法封印时拒绝初始化。

工作进程通过 Unix 描述符传递共享快照，分别拥有 tokenizer 和 ONNX Session。在线封印格式使用自包含单文件 ONNX；带外部权重路径的模型须先重新打包，不能退回可变路径加载。工作进程加载 tokenizer 和 Session 时保留原来的偏移及输入输出门禁。每任务核对快照版本、封印、描述符身份和长度，无须重读模型内容。网关组件指纹使用该快照的已验证文件摘要；其他动态政策和组件一致性检查继续执行。

源目录变更不会改写正在使用的快照。它既不会被旧池加载，也不会被旧保护包版本声明为新模型。发布新版本须创建新快照、新池和新保护包；在途请求完成后关闭旧资源。源目录删除后旧快照仍可服务。保留单次进程执行器及显式可变包模式用于全量校验对照。

每个池只保存一份制品快照，各工作进程的原生运行资源仍独立占内存。封印的制品页不能仅用工作进程 RSS 衡量，资源预算须另计 snapshot 字节数与 HTTP 应用进程数。关闭池先回收所有工作进程和槽线程，再关闭快照描述符。解释器正常退出时通过 multiprocessing finalizer 在子进程 join 之前执行同一清理，避免嵌入式调用者漏关池使退出挂起；显式关闭仍是应用的首选生命周期。

## 预热与回收

每个工作进程在发送 ready 前执行非空合成文本的实际前向计算。应用 lifespan 在对外服务前预热全部槽；readiness 验证所有槽完成预热并存活。回收以任务数、年龄、工作进程峰值 RSS 和异常为依据，默认最多 8192 个成功请求、3600 秒、2048 MiB 峰值 RSS，内存阈值为零表示显式关闭该项。多槽任务上限略微错开，均不超过配置上限。

完成显式预热后，池在空闲时主动预热替代进程。重建失败保留未就绪状态并限制重试频率。超时、取消或原生失败仍须确认旧进程退出后才能替换。年龄和 RSS 是任务边界上的回收阈值，空闲年龄约每秒检查；不是抢占运行中任务的硬定时器或操作系统内存限额。预热不计入业务成功任务数，初始化和队列等待仍受各自提交时预算约束。直接调用池的首次快照创建也发生在已准入的执行槽内，不增加队列外等待者。

## 合批与调度

请求内每个文本片段只分词一次，严格验证原文 code point 偏移；窗口按长度分组跨片段合批。批次同时受最多 32 个窗口和总 padding token 预算约束，结果按片段索引归还，独立解码并合并，禁止跨片段合并实体。

池支持在有界聚合等待内收集多个短请求；默认一请求/批、零主动等待、512 字符分类阈值，关闭跨请求合批。2 ms、8 请求为候选配置，须在目标硬件上证明收益后启用。窗口长度差异超过 25% 时拆成不同前向批次，减少 padding。聚合等待受原始截止时间约束。总在途请求数不得超过执行槽数加等待上限；已进入批次的成员仍占用准入容量，不能通过出队扩大容量。不同请求的正文、跨度和恢复映射不共享，只有固定版本的模型资源共享。

一个批次使用所有成员中最早的截止时间。任一成员在运行中取消、超时或推理失败，整个批次失败，不交付部分或过期结果，并确认进程回收；其他成员不自动重试或延长预算。各成员收到独立构造的异常对象，槽线程释放请求与错误引用，避免跨请求共享 traceback。性能报告标记共享批次规模，各成员观测到的共享推理耗时不能相加作为独立 CPU 时间。

多个槽时长请求至多占用 W-1 个槽，保留短请求执行容量；短请求优先，等待超过 100 ms 的可执行旧请求恢复队列优先级。单槽配置无法抢占正在执行的原生前向计算。长短分类使用字符数作为保守调度指标，不跳过任何文本的检测。

## 窗口与线程配置

窗口长度包含 CLS/SEP，步长指内容 token 的前进量；重叠为窗口长度减二再减步长。较大窗口和较小重叠必须通过分类型召回、边界覆盖、误脱敏及尾部实体回归后才能采用。可选句界切分只能在合法 token 边界切分，保持覆盖、重叠和模型 token 上限；不得按字符估算截断输入。

未显式设置 ORT 线程数时，将可见物理核心和 cgroup-v2 CPU 配额所允许的线程预算分摊到工作进程，最少一个线程。会话使用顺序算子执行并关闭空闲线程自旋。明确配置的线程数保持操作员选择；应联合压测进程数、线程数、合批和业务文本长度分布。

## 验收

功能测试覆盖内核禁止写入、损坏包拒绝、源目录变更时旧版本稳定、新版本重新校验、跨片段与跨请求偏移隔离、实际全槽预热、回收和关闭、批次取消、准入容量和短请求保留槽。真实模型评测固定模型摘要和样本摘要，分别报告 NER 与完整检测质量、排队、冷启动、吞吐、尾延迟和内存。合成样本合格不代表真实业务准入，也不代表 HTTP 全链路达到目标吞吐。
