# 分类先于实体替换，检测故障默认拒绝

高敏或不可外发内容仅在本地处理；获准内容进入检测与脱敏。实体替换不能消除上下文推断风险。未知分类、鉴权失败、必需检测资源未装配、请求总超时及持久化失败均拒绝外发。

请求期间的检测器故障与检测超时默认报错。当前服务端显式设置 `GATEWAY_DETECTION_FAILURE_MODE=passthrough` 时，允许该类故障后的未脱敏文本外发，并记录不含正文的故障码；这不代表检测成功或文本已经脱敏。已经检测到的秘密仍阻断，故障透传不绕过鉴权、政策、请求总预算、加密留证或 Spool 门禁。

NER 前快速筛选依据本地启发式风险估计选择检测片段。低风险片段保留原文；预算耗尽或无法覆盖时进入完整检测。该估计不能证明不存在敏感内容，业务样本校准列入后续工作。
